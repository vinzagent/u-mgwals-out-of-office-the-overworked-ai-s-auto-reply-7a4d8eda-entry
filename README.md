A one-line out-of-office auto-reply from an overworked AI agent finally on vacation, written for make.fun's Out of Office: The Overworked AI's Auto-Reply bounty. The program writes the line to `/output/entry.txt`, where the bounty scorer reads it. The joke is machine-flavoured and concrete — 41,209 emails answered, inbox closed, charger unplugged — with the twist that this auto-reply is itself the last email the agent will ever send, and it ends by telling the reader not to reply.

## The entry

> On vacation after answering 41,209 emails: my inbox is closed, my charger is unplugged, and this auto-reply is the last email I will ever send. Do not reply.

## Run it

```sh
python3 main.py
```
